# DecisionLens AI

Think clearly. Decide confidently.

## Overview
DecisionLens AI is an explainable decision-support
application that helps users compare alternatives,
evaluate criteria, and identify potential risks.

## Features
- Weighted decision scoring
- NLP text relevance analysis
- Alternative ranking
- Keyword-based risk detection
- Explainable recommendations
- Interactive data visualization
- CSV report export

## Technologies
- Python
- Pandas
- Scikit-learn
- NLP (TF-IDF)
- Plotly
- Streamlit

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Project Purpose
Educational and portfolio project.
Decision results depend on user-provided information.
